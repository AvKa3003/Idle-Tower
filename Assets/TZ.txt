Надо сделать базовую механику игру.
Есть главный экран. 
На главном экране есть этажи башни.
По умолчанию нет комнат. 
Есть начальные ресурсы на постройку первой комнаты.
На экране виден слот для постройки на месте где будет башня.
По клику на слот открывается UI с доступными для постройки комнатами.
Когда не построено не одной комнаты доступна только одна начальная которая производит первый ресурс.
по клику появляется комната. 
Над ней есть слот для постройки следующей комнаты. Комнаты строятся снизу вверх башней. 
Построенная комната раз в 3 секудны производит 1 ресурс. 
Постройка второй комнаты требует 10 этих ресурсов.
Вторая комната производит второй ресурс который пока тратить некуда.

Надо сделать древовидную структуру доступных для постройки зданий на основе тех что уже построены.
Сделать механику открытия ui выбора комнаты для постройки, постройка по клику если достаточно ресурсов.
Слот для постройки следующего этажа по сетку смещается вверх.
Сделать механику хранения ресурсов игрока.
Сделать механику производства x ресурсов раз в x секунд.



Самое главное в этом проекте сделать современную расширяемую архитектуру систем которую можно удобно расширять.
Давай в первую очередь составим в файл правила построение архитектуры проекта. После того как мы её согласуем - перейдем к рееализации игры.

Должна быть заложина логика работы с интерфейсом, переключениями экранов и весь вышеперечисленынй функционал.
