================================================================================
ТЕСТЫ: СЕЙВ / LOAD КАРТЫ + МИГРАЦИИ (этап D)
================================================================================
Спека правил: Assets/map-save-migration.txt
Сейчас — ручной прогон. Позже каждый ID → автотест.

Как пользоваться:
  - Перед кейсом с правкой MapConfig: сохрани прогресс (или дождись автосейва),
    выйди из Play, поменяй ассет, снова Play (Load).
  - Смотри: кошелёк, панель рейда, соседей на карте, Console, модалку офлайна.


================================================================================
A. ОБЫЧНЫЙ СЕЙВ И ЗАГРУЗКА (конфиг карты не трогаем)
================================================================================

----- A1. Простой рейд без активного набега -----

Что сделать:
  1. Открыть карту, кликнуть лагерь (PreCapture).
  2. Выставить состав армии, убедиться что не на паузе (Play).
  3. Сохранить (или дождаться автосейва) и перезапустить игру / Load.

Что проверить:
  - Клетка снова PreCapture.
  - Состав армии тот же.
  - Не на паузе (если так и было).
  - Карта открывается без ошибок.

----- A2. Сохранить посреди рейда -----

Что сделать:
  1. Запустить рейд, подождать примерно половину таймера.
  2. Сразу Save → Load (не ждать конца рейда).

Что проверить:
  - После Load рейд всё ещё идёт, прогресс примерно тот же.
  - Доиграть до конца: награда приходит из текущего PreCapture.
  - Игра не падает.

----- A3. Уже захваченный лагерь (Dead) -----

Что сделать:
  1. Довести лагерь до Captured с PostCaptureMode = Dead.
  2. Save → Load.

Что проверить:
  - Клетка Captured, спрайт/вид захвата на месте.
  - Нет автозапуска рейдов.
  - Пауза не «залипла» (для Dead пауза не нужна).

----- A4. Туман и соседи после Load -----

Что сделать:
  1. Захватить лагерь так, чтобы соседние клетки стали Interactive.
  2. Save → Load.

Что проверить:
  - Соседи снова Interactive (presence не из сейва, а пересчёт).
  - Дом и зона видимости выглядят как до перезапуска.

----- A5. Старый сейв без mapCells -----

Что сделать:
  1. Подложить сейв версии без массива mapCells (или пустой mapCells).
  2. Запустить игру (Load).

Что проверить:
  - Нет exception / чёрного экрана.
  - Карта живая: клетки с нулевым прогрессом рейдов.
  - Кошелёк и башня из сейва на месте.

----- A6. Двойной круг Save → Load → Save -----

Что сделать:
  1. Наиграть состояние (армия, фаза).
  2. Save → Load → снова Save.
  3. Сравнить в JSON ключевые поля mapCells (coord, behaviorType, phase, армия).

Что проверить:
  - Данные не «плывут» и не обнуляются после второго сейва.


================================================================================
B. ТОТ ЖЕ RAID, ТОТ ЖЕ PostCaptureMode, НО ПОМЕНЯЛИ БАЛАНС В MAPCONFIG
================================================================================

----- B1. Меняем награду во время идущего PreCapture-рейда -----

Что сделать:
  1. Запустить рейд на ~50%.
  2. Save, выйти из Play.
  3. В MapConfig у этой клетки изменить PreCapture.Rewards (сделать заметно другие).
  4. Play / Load, дождаться конца рейда (или офлайном).

Что проверить:
  - Сразу после Load клетка на паузе (новый рейд сам не стартует).
  - Текущий рейд доигрывается.
  - В конце приходит НОВАЯ награда из конфига, не старая из момента старта.
  - Пока не нажмёшь Play — следующий рейд не уходит.

----- B2. Меняем требования, рейда нет -----

Что сделать:
  1. Выставить PlannedArmy, не запускать рейд.
  2. Save → в конфиге поменять RequiredUnits или Duration → Load.

Что проверить:
  - Пауза включена.
  - Состав армии сохранился (если юниты ещё существуют в балансе).

----- B3. Farm + активный рейд + смена FarmConfig (этап E, пока отложить) -----

Когда появится геймплей RaidFarm:
  1. Captured + Farm, идёт farm-рейд.
  2. Save → поменять FarmConfig.Rewards → Load.

Что проверить:
  - Pause, рейд доигрывается с новой наградой, без автостарта.

----- B4. Captured Dead, меняем что-то в Site (спрайт / PreCapture) -----

Что сделать:
  1. Captured + Dead.
  2. Save → поменять CapturedSprite или поля PreCapture → Load.

Что проверить:
  - Остаётся Captured.
  - IsPaused = false (Dead не должен остаться «на паузе»).


================================================================================
C. СМЕНИЛИ PostCaptureMode В КОНФИГЕ
================================================================================

----- C1. Farm → Dead, пока шёл рейд -----

Что сделать:
  1. Captured + RaidFarm, запустить рейд (запомнить, какая награда была при старте).
  2. Save → в конфиге PostCaptureMode = Dead → Load.

Что проверить:
  - Сразу начислилась награда ИЗ СЕЙВА (та, что была при старте рейда).
  - Активного рейда больше нет.
  - Mode Dead, без паузы / без автостарта.

----- C2. Farm → Dead, рейда не было -----

Что сделать:
  1. Captured + Farm, на паузе, без активного рейда.
  2. Save → mode Dead → Load.

Что проверить:
  - Лишней награды нет.
  - Captured, без паузы.

----- C3. Dead → Farm -----

Что сделать:
  1. Captured + Dead.
  2. Save → mode RaidFarm → Load.

Что проверить:
  - Клетка на паузе (Farm сам не ест армию).
  - После ручного Play — уже правила Farm (когда E будет готов).

----- C4. Passive → Farm (когда будет Passive) -----

Что сделать:
  1. Captured + Passive.
  2. Save → mode Farm → Load.

Что проверить:
  - Pause на Farm.

----- C5. PreCapture + активный рейд, в Site крутанули только PostCaptureMode -----

Что сделать:
  1. Идёт PreCapture-рейд.
  2. Save → сменить только PostCaptureMode (Dead↔Farm), PreCapture не трогать → Load.

Что проверить:
  - Записать фактическое поведение (прогресс / пауза / награда).
  - Не должно «сломать» дозахватный рейд без причины; при сюрпризе — уточнить спеку.


================================================================================
D. В СЕЙВЕ PostCaptureMode, КОТОРОГО БОЛЬШЕ НЕТ В ENUM
================================================================================

Как сымитировать: в JSON сейва руками поставить savedPostCaptureMode = 99
(или старое число удалённого значения).

----- D1. Captured, без активного рейда -----

Что сделать:
  1. Иметь Captured-сейв.
  2. Подменить savedPostCaptureMode на несуществующий.
  3. Load.

Что проверить:
  - Клетка Captured «как только что захватили».
  - Активного рейда нет.
  - Pause только если в конфиге сейчас Farm.
  - В Console есть warning про неизвестный mode.

----- D2. То же, но в сейве был активный рейд -----

Что сделать:
  Как D1, но hasActiveRaid / activeRaidRewards заполнены.

Что проверить:
  - Награда из activeRaidRewards выдана.
  - Рейд сброшен, состояние «свежий Captured» под текущий mode.


================================================================================
E. ПОМЕНЯЛИ ТИП КЛЕТКИ (Behavior)
================================================================================

----- E1. Raid с активным рейдом → Decorative -----

Что сделать:
  1. Запустить рейд на клетке.
  2. Save → у Entry сменить Cell на декоративную (дорога/река) → Load.

Что проверить:
  - Награда за начатый рейд пришла (кошелёк / модалка офлайна).
  - На coord обычная декорация, без рейд-панели.

----- E2. Captured Raid без рейда → Decorative -----

Что сделать:
  1. Captured idle.
  2. Save → Cell = Decorative → Load.

Что проверить:
  - Награды нет (компенсации за «просто Captured» нет).
  - Декорация с нуля.

----- E3. Decorative → Raid -----

Что сделать:
  1. Декоративная клетка в сейве.
  2. Save → Cell = Raid → Load.

Что проверить:
  - Новый Raid с чистым PreCapture.
  - Нет ложных наград.


================================================================================
F. ДОБАВИЛИ / УБРАЛИ КЛЕТКИ НА КАРТЕ
================================================================================

----- F1. Удалили coord, на котором шёл рейд -----

Что сделать:
  1. Активный рейд на клетке.
  2. Save → убрать Entry с этим coord из MapConfig → Load.

Что проверить:
  - Награда за рейд выдана.
  - Клетки на карте нет.
  - Игра не падает.

----- F2. Удалили Captured idle coord -----

Что сделать:
  1. Captured без рейда.
  2. Save → удалить Entry → Load.

Что проверить:
  - Без награды, без crash.

----- F3. Добавили новый Raid coord -----

Что сделать:
  1. Save со старой картой.
  2. Добавить новый Entry с Raid → Load.

Что проверить:
  - Новая клетка в стартовом PreCapture (пустой прогресс).

----- F4. Перенесли HomeCoord -----

Что сделать:
  1. Save.
  2. Поменять HomeCoord и/или кто стоит на старом доме → Load.

Что проверить:
  - Зона Interactive/Visible считается от нового дома.
  - Старая клетка ведёт себя по своему новому Behavior.


================================================================================
G. ЧИСТКА ДАННЫХ И ЛИМИТЫ
================================================================================

----- G1. Уменьшили MaxCompletedRaids -----

Что сделать:
  1. PreCapture с CompletedRaids = 2, в конфиге было Max = 3.
  2. Save → MaxCompletedRaids = 1 → Load.

Что проверить:
  - Клетка стала Captured.
  - Pause только если PostCaptureMode = Farm.

----- G2. В армии юнит, которого удалили из игры -----

Что сделать:
  1. PlannedArmy с двумя юнитами.
  2. Save → убрать один ResourceDefinition из AllResources (или id) → Load.

Что проверить:
  - Пропавший юнит исчез из состава.
  - Второй остался.

----- G3. В армии попал не-юнит -----

Что сделать:
  Подменить в сейве PlannedArmy ресурс с IsUnit=false → Load.

Что проверить:
  - Такая строка вычищена.

----- G4. Сломанный JSON state клетки -----

Что сделать:
  В behaviorStateJson написать мусор → Load.

Что проверить:
  - Warning в Console.
  - Эта клетка с default state.
  - Остальной сейв (кошелёк, башня) загрузился.


================================================================================
H. ОФЛАЙН-МОДАЛКА И МИГРАЦИЯ
================================================================================

----- H1. Офлайн доигрывает рейд без смены конфига -----

Что сделать:
  1. Рейд почти закончен.
  2. Save, подождать дольше duration (сменить системное время / watermark), Load.

Что проверить:
  - Рейд завершён в catch-up.
  - Награда видна в модалке офлайна.

----- H2. Награда миграции при нулевом офлайн-времени -----

Что сделать:
  1. Кейс с GrantRewards (например E1 или C1).
  2. Load почти сразу после Save (нет wall-time офлайна).

Что проверить:
  - Модалка всё равно показывает дельту миграции (ресурсы прибавились).

----- H3. Часы отстали от watermark + есть награда миграции -----

Что сделать:
  1. Сейв с watermark «в будущем» относительно ОС.
  2. Плюс миграция с выдачей награды → Load.

Что проверить:
  - Тики офлайна не крутятся.
  - Награда миграции всё равно в дельте / кошельке.
  - Watermark не ломает следующие сейвы странным откатом.

----- H4. Ни офлайна, ни наград миграции -----

Что сделать:
  Обычный Load без изменений конфига и без прошедшего времени.

Что проверить:
  - Модалка офлайна не обязана показываться.


================================================================================
I. ПАУЗА И КНОПКИ
================================================================================

----- I1. После миграции на Dead -----

Что проверить:
  - IsPaused = false.
  - Play/Pause для Captured+Dead недоступны (как в обычной игре).

----- I2. После миграции на Farm с Pause -----

Что проверить:
  - Стоит пауза, автостарта нет.
  - Play снимает паузу; дальше автостарт по правилам Farm (этап E).

----- I3. После B1 (PreCapture + пауза) -----

Что проверить:
  - Пауза после Load.
  - Play снова разрешает автостарт, когда хватает юнитов.


================================================================================
J. НЕ СЛОМАЛИ ОСТАЛЬНОЕ
================================================================================

----- J1. Башня и кошелёк -----

Что сделать:
  Load сейва с mapCells и построенными комнатами.

Что проверить:
  - Комнаты, ресурсы, тик на месте; карта тоже.

----- J2. Новая игра после Load -----

Что сделать:
  Load → затем NewGame (если есть) / очистка сейва + старт.

Что проверить:
  - Карта снова из чистого MapConfig, без чужого прогресса рейдов.

----- J3. Автосейв пишет карту -----

Что сделать:
  Прогресс на карте → пауза приложения / quit / автосейв.
  Открыть JSON.

Что проверить:
  - В файле есть mapCells с актуальными coord / phase / армией.
